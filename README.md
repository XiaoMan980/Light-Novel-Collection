# 轻小说合集 (Light Novel Collection)

个人轻小说收藏合集，用于整理、索引与存档所收集的轻小说作品。

## 目录结构

- `index.csv`：全库书目索引（UTF-8 编码），字段说明见下方
- `书名/`：每本书一个目录，存放电子书文件（`epub` / `txt`）与 `简介.md`
- `README.md`：本说明文件

## 收录与命名规范

- 以「书名」建立独立目录，如 `关于我转生变成史莱姆这档事/`
- 电子书统一保存为 `书名.epub` 主文件，另附 `.txt` 便于阅读
- 每本目录下放 `简介.md`，记录作者、译版、来源与备注
- 若同一本书存在多个译版（台版 / 网译 / 短篇），在文件名或 `index.csv` 的「译版」列标注

## index.csv 字段说明

| 字段 | 说明 |
| --- | --- |
| 书名 | 中文书名 |
| 原名 | 日文 / 英文原名 |
| 作者 | 原作者 |
| 卷数 | 卷数概览（如「多卷」） |
| 状态 | 完结 / 连载中 / 休载 |
| 译版 | 台版 / 网译 / 短篇 |
| 简介 | 一句话简介 |
| 来源 | 内容来源平台（如轻小说文库、哔哩轻小说） |
| 格式 | 收录格式（epub / txt） |

> 说明：`index.csv` 中卷数与译版信息为整理时快照，仅供参考，请以源站最新版本为准。数据来源为公开可检索的轻小说站点信息。

## 使用说明

- 用支持 CSV 的表格工具（Excel / WPS / LibreOffice）打开 `index.csv`，注意选择 UTF-8 编码。
- 新增书籍：在 `index.csv` 追加一行，并新建对应 `书名/` 目录放入电子书文件与 `简介.md`。
